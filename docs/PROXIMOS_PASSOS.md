# Próximos passos — Idle Game Agent

1. Validar o MVP local e testes automatizados no Windows e no GitHub.
2. Coletar dados reais de XP/h, itens, mercado, taxas e custos nos dois jogos utilizando recursos permitidos.
3. Para IO: revisar termos e extensão divulgada pela equipe, mapear elementos de interface e desenvolver adaptador com controle de ações, logs, modo dry-run e parada de emergência, sem pagamentos ou saques automatizados.
4. Para World: manter somente análise e captura de landing pública até obter autorização explícita para qualquer automação de conta.
5. Separar gemas, anúncios, vendas concluídas e saques efetivamente recebidos no relatório financeiro.
6. Comparar a heurística com um modelo local e avaliar se a complexidade adicional melhora os resultados.
7. Jamais comprometer credenciais, cookies, dados de conta ou capturas privadas no GitHub.

Os dois jogos têm economias e permissões diferentes. Nenhum rendimento foi comprovado neste projeto.
